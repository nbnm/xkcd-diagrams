# Editor guide

[Back to the project README](../README.md)


The app opens a T1A data platform example. Press **X** to select container placement, then click the canvas to place it; **Escape** cancels. E and X work throughout the diagram window while you are outside text fields, and keep normal typing in labels, search, and source editing. Use File → New Diagram for a blank canvas. Drag shapes and vendor symbols from the library into the canvas or a boundary, or click a library entry to add it. Container is the first library item, with Connector directly below it. Its inspector controls horizontal, vertical, or free arrangement; individual systems have no arrangement controls. Drag within a stack to reorder it, or into another container to change ownership. Type rules block invalid drops.

The bottom status bar shows the saved diagram's full file path. Click it to open its folder in Finder with the file selected. Long paths wrap so the complete path remains visible. Unsaved diagrams show **Unsaved diagram** until saved. Diagram titles appear in the tabs; the window title shows the app name.

Set **Canvas placement → Custom rows and columns** to define a grid with 1–32 rows and columns. Select an item and use Row, Column, Row span, and Column span to assign its cell. Drag between cells to move items; single-cell items swap when dropped onto one another. Containers stretch across their assigned spans while arranging their own contents. Unassigned items fill available cells in child order; adding items or increasing spans adds rows when needed. Grid changes reroute connectors. Add Container Below Diagram keeps a custom grid and creates a new full-width row below the other items. Faint cell guides appear only in the editor; PNG and SVG exports contain the diagram.

Set **Canvas placement → Free placement** in the inspector to mix top-level rows and columns while each container keeps its own arrangement. The canvas has no top or left boundary: dragging, placing, pasting, and arrow-key nudging can cross the origin without shifting other items. Pan to reach any area and use Fit to show the whole diagram. Switching from a row or column preserves current positions. Use **Diagram → Add Container Below Diagram** for a wide horizontal container under the whole diagram, or select an existing top-level container and choose **Place below diagram**. Container Width and Height set minimum dimensions; **Fit to contents** restores automatic sizing. Drag top-level items freely; connectors follow their new positions. These settings persist in JSON and image exports.

Press **E** to select Connector, or choose it in the toolbox or Diagram menu (⌘K), then drag from the source to the destination, or click each in turn. You can also drag the Connector toolbox item onto a source, then click a destination or drag from that source to it. Dropping the tool on empty canvas activates it so you can choose a source. A live right-angle preview highlights the destination; releasing on empty canvas or the source creates no connection and keeps the source ready for another attempt. Both systems and container boundaries can be connected; Escape on the canvas cancels. Connecting leaves item positions unchanged and creates one undoable edit. Every connector meets its source and destination edge at a right angle, with a short perpendicular approach before any bend. Click a connection or its label to edit arrows, endpoint sides, line pattern, and manual path points; manual points gain right-angle bends between them. Older `straight` routes also use this geometry. Changing a container to a horizontal or vertical stack resets affected connector sides and manual bends so connections follow the new arrangement; unrelated connections retain their settings. Select a system to edit its label, shape, width, and logo from a vendor-grouped picker. The Documents group contains File, XLSX, PDF, and DOCX. They keep a fixed 3:4 width-to-height ratio with folded corners, persistent format marks, and editable labels. Width changes and text or logo growth resize both dimensions together; the spreadsheet grid and document lines match their library previews. Queue uses a stack of message outlines, and library thumbnails use the same geometry as the canvas. Database labels and logos sit below the curved lid, with space above the lower outline; cylinders expand to fit wrapped text without covering their border.

Use **App appearance → Light / Dark** at the bottom of the library to choose the interface appearance. This preference is remembered across launches and applies to every diagram. It does not change the document, image exports, or undo history. The toolbar’s **Color theme** control selects Standard, Blueprint, Dark, SecondStack, or 8FDE. A separate **Sketch** toggle works with all five colors; both settings are saved in the diagram and used by image exports.

All five color themes support clean or sketch strokes. Sketch uses restrained, seeded pen variation on shape outlines, curved symbols, container boundaries, document details, and connectors. Connector bends and attachments retain straight sections and 90-degree angles. Turn Sketch off for precise outlines. Vendor marks stay undistorted in every combination. With **Style default**, Sketch uses Chalkboard SE; clean Standard, Dark, SecondStack, and 8FDE use Helvetica, and clean Blueprint uses Menlo. A custom Font choice applies to every combination and survives toggling Sketch. Dark uses charcoal paper (`#181818`) with light gray ink and logos. Blueprint uses saturated blue paper (`#0b3d91`), white ink and marks, and a thin drafting grid of 20-point squares with slightly stronger lines every 100 points. Its placement matches in the canvas, PNG, and SVG. Typography remains adjustable. With an item selected, **Selected text → Text size** changes only that shape’s label, container title, or connector label. **Use default text size** removes its override. Container title sizes do not propagate to children. With nothing selected, **Default text size** sets the document default for system labels; container and connector defaults stay at 14 and 12 points. Large labels expand their shapes, headers, or label backgrounds to stay readable, and connectors follow the resulting geometry. Select a shape, container, or connector to adjust its line width in its own inspector section; this affects that item alone. Use default removes its custom width. The width control is unavailable without a selection; existing diagrams retain their saved default width. The app name follows this project's folder name, and the app icon shows a stick-figure draftsman drawing a blueprint. That character is a provisional interpretation of Ubino.

The two brand themes take their palette from [SecondStack](https://secondstack.ai/) and [8FDE](https://8fde.ai/). **SecondStack** uses near-black paper (`#0b0d10`), charcoal system surfaces (`#14171b`), off-white text (`#f4f6f8`), and cyan (`#2fb5f4`) container titles, boundaries, and connectors. **8FDE** uses white paper and container backgrounds, `#0c6e85` object outlines and detail lines, dark navy text (`#111827`), and violet (`#5d4be8`) container titles, boundaries, and connectors. Body labels and vendor marks remain neutral; white marks on light paper retain a dark backing. Choose either in the Color theme menu, and use Sketch independently. The same palette is used in the canvas, PNG, and SVG. Agents select `theme.preset: "secondstack"` or `"8fde"`; custom fonts and per-item widths and text sizes are preserved.

Use the toolbar Zoom In and Zoom Out buttons or ⌘= and ⌘− to change the canvas scale by a factor of 1.25, from 20% to 300%. The toolbar shows the current percentage; zoom buttons stop at the limits. Button zoom stays centered on the viewport. Pinch or Command-scroll zooms around the pointer. Drag empty canvas or Option-drag to pan, and use ⌘0 to fit. Zoom changes only the view, leaving document geometry, exports, and undo history intact. Undo and redo support document edits. Deleting connected elements shows a confirmation sheet attached to the editor; the deletion and attached connectors can be restored together with Undo. Open or save JSON through File; saved documents autosave subsequent changes. External edits reload when the app is clean, or surface a conflict when local changes exist. JSON source editing validates before applying. Export SVG or PNG from the toolbar.

Keep several diagrams open in the tab bar. **⌘T** or the **+** button creates a blank diagram; **⌘N** does the same. **⌘O** opens one or several files in new tabs; an already-open file selects its existing tab. **⌘⇧[** and **⌘⇧]** switch tabs. **⌘W** or a tab's **×** closes that tab, prompting for unsaved changes; closing the final tab leaves a blank editor. Each tab keeps its own diagram, selection, undo/redo history, and zoom/pan position while switching. Copy and paste work between tabs. Saving and exporting apply to the active tab; Save As prevents overwriting a file open in another tab. Inactive saved tabs also monitor external changes. Closing the window or quitting checks every unsaved tab. Saved file tabs and the active saved tab reopen on the next launch; unsaved diagrams must be saved to reopen after quitting.

Enable **T1A watermark** in the Diagram appearance inspector to place the official logo in a reserved bottom-right footer on the canvas and PNG/SVG exports. The setting is saved per diagram and uses light ink in Blueprint, Dark, and SecondStack.

Older diagrams retain their appearance: `signature-sketch` opens as Standard with Sketch on; legacy Standard, Blueprint, and Dark open with Sketch off. Saving writes the color as `theme.preset` and the independent boolean as `theme.sketch`. New diagrams default to Standard with Sketch on.

## Toolbox shortcuts and editing

Click the canvas, or press Escape to leave a name/search field, then use a toolbox shortcut and click to place the item. Escape also cancels placement or a connector. The same keys appear beside the presets and in their hover tooltips. The Toolbox menu lists every tool. Existing click-to-add and drag-and-drop controls still work.

| Control | Key | Control | Key |
| --- | --- | --- | --- |
| Container | X | Connector | E |
| System | S | Database | D |
| Queue | Q | AI Agent | A |
| User | U | Text | T |
| File | F | XLSX | L |
| PDF | P | DOCX | W |

For platforms, press the group number, release it, then press the item key. The status bar shows the available choices after the first key. For example, **2 then G** selects Genie Agent; **3 then V** selects Azure Virtual Machine.

**⌘C / ⌘V** copy and paste the selected item. A container includes its nested contents, layouts, frozen logos, and internal connectors. Each paste gets fresh identifiers and its own Undo step. In free placement, repeated pastes are offset by 24 points; stacks and grids arrange the copy. Pasting within the same diagram creates a sibling in the original parent. Across diagrams, it uses the selected container or the canvas, preserving the destination theme and keeping conflicting logo assets separate. A connector can be copied within its original diagram while both endpoints exist. Clipboard contents are portable between app windows. Text fields and source JSON keep normal text copy/paste behavior.

**Double-click** a shape, container, or connector on the canvas to focus its name field and select the current text for quick replacement. Press Escape or click the canvas to return to diagram shortcuts.

## Free Drawing and Timeline

Choose a mode in the top-left Mode menu. Work stays in separate tabs; switching modes reuses a tab of that type or creates one. The + button and ⌘T create a document in the current mode. File offers explicit New Diagram, New Free Drawing, and New Timeline commands.

In Free Drawing, use P for Pen, V for Select, T for Text, and E for Eraser. Pen strokes smooth mouse jitter without discarding raw samples. Defaults affect new strokes; the selected-stroke inspector changes only that stroke. Erasing deletes complete marks. Click with Text to type on the canvas, use ⌘Return to finish, or Escape to cancel; double-click a text item to edit it again. Select moves strokes/text, and ⌥ drag pans. Each drawing, move, or erase gesture is one undo step. Copy/paste works for strokes and text.

In Timeline, N adds a task and M adds a milestone. The inspector edits names, dates, duration, owner, completion, predecessors, and row order. Normal tasks last at least one calendar day; milestones have a zero-day duration. Drag bar bodies to move tasks, either edge to resize them, or task-name rows vertically to reorder. Arrow keys move a selected task by one day or one row; Shift-left/right moves by ten days. Weekends are included and shaded; there is no business-day calendar. Days/Weeks/Months changes only the chart density. Predecessor links do not automatically reschedule tasks. A warning appears if a task starts on/before a predecessor's inclusive finish, and dependency cycles are rejected. Resource leveling, critical-path calculations, and Microsoft Project import/export are outside this implementation.

Themes, Sketch, watermark, JSON source editing, autosave, tabs, undo/redo, PNG/SVG exports, and guarded CLI writes apply to all modes. Files retain schema version 1 with an optional mode and the corresponding drawing/timeline payload; old files without a mode remain diagrams. The CLI supports init --mode drawing|timeline and inspect includes the mode-specific content.
